# sql-database-development

# About
*	Developed a relational database using SQL Server to manage employee records, job classifications, project assignments, and project expenses, implementing primary keys, foreign keys, and integrity constraints
*	Wrote SQL queries using joins, filtering, sorting, grouping, and aggregate functions to retrieve employee information and calculate project-level work hours, employee counts, and total charges
*	The report includes the SQL queries as well as additional information about the integrity constraints and relationships. Also includes the database diagram.
